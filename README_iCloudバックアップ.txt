推し活グッズ帳（端末内保存＋iCloud Drive手動バックアップ）

GitHub Pagesのリポジトリに、次の3ファイルを元のファイル名のまま置き換えてください。
- index.html
- manifest.json
- sw.js

iPhoneでバックアップする方法：アプリのメニュー →「iCloud Driveにバックアップ」→ iOS共有画面で「ファイルに保存」→ 保存先に「iCloud Drive」を選択。

復元：アプリのメニュー →「JSONバックアップを取り込む」→「ファイル」アプリのiCloud DriveからJSONを選択。

注意：これはiCloudとの自動同期ではなく、ユーザーが操作して行う手動バックアップです。復元前に現在のデータもバックアップしてください。同じIDのレコードは更新されます。アプリの保存領域はブラウザ／ホーム画面アプリの利用形態やサイトのオリジンに依存するため、今後使う入口を固定してください。
