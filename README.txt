推し活グッズ帳 iCloud Driveバックアップ修正版

反映するファイル:
- index.html
- manifest.json
- sw.js

GitHubリポジトリの同名ファイルをこのZIP内のファイルで置き換えてコミットしてください。
設定（右上の ⋮）を開くと、画面上部に「iCloud Driveバックアップ」枠が表示されます。

バックアップは手動です。ボタンから共有/保存画面を開き、「ファイルに保存」→「iCloud Drive」を選択してください。
Google同期は使用しません。Safari/ホーム画面アプリで保存領域が異なる場合があるため、実際に使う入口で復元と保存を確認してください。
